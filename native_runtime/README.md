# Native execution runtime — development

This worker must run only inside the restricted Docker launcher. Never import or execute
candidate code on the Windows host. The image contains Python and pinned NumPy; build
records must pin the resolved image ID and base digest before scientific experiments.

The evaluator offers all feasible bins including unused ones, matching the audited native
packing action contract. It is an evaluator integration component, not complete native
EoH/FunSearch search reproduction. Candidate score vectors must be finite and correctly
shaped. Every returned assignment is independently checked on the host.

Containment is not established by a Dockerfile. Network, mounts, privileges, resource
limits, output limits, termination and cleanup must be verified by executable probes
before model-generated Python is admitted. The Docker daemon/socket must never be exposed
inside a candidate container. No workspace mount or host environment inheritance.
